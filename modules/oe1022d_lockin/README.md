# OE1022D Lock-in

Beta 版本。用于两路电压的同步参考测量，默认读取每个通道的
`1f` 和 `2f`；典型接法是 **A 接纵向电压，B 接横向霍尔电压**。两通道分别取
快照，同一谐波的 X/Y/R/θ 来自同一条 `SNAPD?`；A/B 及不同谐波之间不是原子采样。

## 接线和配置

- **外部源**：选择 External reference。若使用 [6221 AC 模块](../keithley_6221_ac/README.md)，
  同时启用两个模块，6221 给样品提供正弦电流，Phase Marker 接到 OE1022D 的两路
  外部参考；也可仅给 A 外参考，把 B 的参考选为 Channel-A。OE1022D 不连接 6221，也不写 Sine Out，可搭配其他外部激励源。
- **OE1022D 单机**：将所选 Sine Out 接到实验电路；该通道使用内部参考，其 TTL
  Out 接到另一通道的外部参考；使用 Sine Out A 时，也可将 Channel 2 reference 选为 Channel-A，在仪表内部共享 A 参考。Sine Out 是带 50 Ω 输出阻抗的电压源，不把设定
  电压写成电流。另一 Sine Out 不由模块控制。
- OE1022D 支持扫描器中的 USB 虚拟串口/RS-232 VISA 地址（`ASRL…::INSTR`）。
  串口参数为 8N1，波特率应与仪表匹配，默认 921600。
- **Settings** 下有 Source、Channel 1、Channel 2 三页；外层 **Status** 显示最新
  读数和状态；主窗口状态卡显示 Ch1 的 X1p、Y1s 和 Ch2 的 X2p、Y2s。各通道可设电压输入、耦合、屏蔽、陷波、动态储备、灵敏度、参考相位、
  时间常数、滚降和两个谐波阶数。OE1022D 的灵敏度、相位和滤波按手册的通道级
  指令设置，不仿照其他型号添加独立的谐波增益或滤波控件。
- Enable/载入设置不连接和写仪表。单机模式 Apply 前填写适合样品的 RMS 电压上限。
  Apply 不启动激励；第一次 Measure 或 Scan 才设置输出。

## SEQ 和 DAT

外部参考模式把 `Measure` 放进外部源的扫描块；单机模式用 `Scan Voltage`。
Measure 合并两个通道为一行。保留原始电压；Measure 本身保持量程，自动量程由 SEQ 中明确插入的 Auto Range 执行。
OE1022D 电压点是非负 RMS 值，非零点须是 1 mV 的整数倍；
零点、SEQ 结束/停止/出错以及 Disable 时，选定的 Sine Out 切到 **DC 0 V** 并读回确认。

DAT 的 `p`/`s` 分别为主/次谐波。保留每路 X/Y/R/θ、仪表读回的实际谐波阶数、频率与状态，
以及样例 DAT 的 `Y1s/X1p`、`Y2s/X1p^2` 等比值和平方量。过载或失锁时相应
导出值留空，原始读数和状态仍记录。如果外部扫频使仪表自动降阶，保留实测阶数和原始读数，
提示阶数变化，涉及该谐波的平方或比值留空。两个模块各自执行本机的频率限制。
状态位：2 输入过载、4 增益过载、16 外参考未锁定。
不计算 V/I；联合使用时主框架把源电流和电压写到同一行，可按源状态和锁相状态筛选，再离线计算。

## 软件 Auto Range（0.1.0b3）

Enable 后可在 SEQ 中插入 **Auto Range**。命令在当前最大激励点分别搜索 A/B 的量程，
随后按默认勾选的 **Optimize dynamic reserve after ranging** 降低动态储备。
搜索使用手动设置和写后回读，不调用仪表的 `AGAND`、`ARSVD`。
原生实现仍保留在后台 `_instrument_auto_range()` 及驱动方法中，SEQ 不分派到该实现。

每路先设置 High Reserve，写后回读，再等待完整的滤波响应时间。实际时间常数和滚降
从仪表读取，整个搜索不改这两个参数：6/12/18/24 dB/oct 分别等待 5/7/9/10 倍时间常数。
每次改变量程或 DR 都重新等待，不发送清除锁存状态的命令。

在无输入过载、参考有效时，根据两组谐波中较大的 R 搜索 20%～80% 满量程占用率，
目标接近 55%。增益过载且还没有安全档时约十倍放大量程；下调碰壁后逐档放大，
本次 High Reserve 搜索不再跳回已失败的档位。最多检查十轮，连续两次合格后才优化 DR。
优化时固定量程，依次尝试 Normal、Low Noise；失败则恢复上一合格 DR 并等待复查。
取消优化时保持 High Reserve。

两路最后都需通过设置回读、滤波不变和占用率检查，实际档位显示在 Status。
档位边界、十轮未收敛或最终占用率验证不通过时报告 Warning，读取并保留仪表实际的量程与动态储备，
SEQ 继续；不标记为自动量程成功，后续 Measure 保留原始读数和状态并按状态告警。
参考失锁、输入过载、通信／设置回读失败或总操作时间不足仍报告 Error 并停止 SEQ。
成功自动量程后的 Measure 不重新选档，发现档位变动或过载／失锁会停止 SEQ。
下一次 Apply 会按 Settings 中的手动值重新设置。

典型定温定场流程：先升电流至本轮最大幅值，执行 Auto Range，再做降电流和反向电流扫描。
正常搜索和未收敛告警不改变激励；致命错误按模块现有安全路径收尾。两路的主、次谐波共用通道级灵敏度与动态储备，不能分别设定。

旧版本 Auto Range 的 `settle_seconds` 参数已移除，旧 SEQ 需删除这个参数；等待现在完全由
实际时间常数和滚降计算。Scan Voltage、Scan Current 自己的等待参数不受此变更影响。
较长时间常数需要足够的框架 `operation_timeout_seconds`：例如 3 s、18 dB/oct 每次检查
等待 27 s，多轮搜索可能超过默认 120 s；程序不会为赶上时限缩短等待或修改时间常数。

SEQ 写法：

```text
T Module Command "oe1022d_lockin" "auto_range" {"auto_reserve":true}
```

首轮实机请用已知负载和示波器核对参考锁定、读数及归零，不要先接未知或脆弱样品。

## USB 通信

这台设备的 USB 文本响应为回车结尾、补零到 4096 字节；驱动只移除下一次文本读取的
前导补零，正文中的非法空字节仍会触发解析错误。固件会丢失紧跟设置写入的查询，
因此每次设置后等待 100 ms，再查询并比较，不自动重发设置。
